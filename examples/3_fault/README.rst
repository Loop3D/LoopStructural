3. Modelling Faults
--------------------
LoopStructural represents each fault as a structural frame (fault
surface, slip direction and extent) rather than a simple step function,
so that faulted surfaces are displaced with realistic kinematics instead
of just being offset in value. These examples cover building a single
fault, networks of interacting faults, customising the displacement
profile (e.g. for drag faults), and updating a fault's geometry after the
rest of the model has already been built.
