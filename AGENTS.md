## Development toolkit

Read `.dev-tools/project.json` for project commands and documentation paths.
Use the installed dev-tools-setup skill to complete or revise project setup.
Before a workflow that requires a constitution, run
`dev-tools doctor --require-constitution` from the project root. If it fails,
report the prerequisite and use dev-tools-setup to resolve it before proceeding.
Project rules take priority over toolkit defaults. Execute only commands
appropriate to the current task. Model selection and delegation depend on
the active agent's capabilities; report unavailable capabilities explicitly.
